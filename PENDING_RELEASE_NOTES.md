- Let `rimworld/spawn_thing` spawn pawns. A pawn race such as `Muffalo` or a pawn kind such as `Colonist` now gives a generated pawn with the kind's default faction. Before, a pawn race failed with an error.
- Spawn things with `rimworld/spawn_thing` as the game's own debug spawner does. A thing made from stuff, such as a wall or a bed, gets its default stuff, and a building belongs to the player. Before, RimWorld logged an error for the missing stuff, and colonists ignored the unowned building.
- Page the children in `rimworld/list_debug_action_children` and `rimworld/get_debug_action`. A generated submenu such as `Spawn thing...` has more than a thousand children, and one reply was too large for agent clients. Pass `offset` for the next page.
- Report traits and work priorities in `rimworld/get_pawn_details`. Traits come with degree and suppressed state. Work priorities list all work types, highest natural priority first, with priority, disabled and permanently disabled state, and whether the Work tab shows them. The reply also says whether manual priorities are on.
- Describe the x and z of `rimworld/get_cells_info`, `rimworld/frame_cell_rect` and `rimworld/screenshot_cell_rect` as the south-west cell of the rectangle. Before, the text said top-left. The rectangle extends north and east from that cell.
- List each label once in `rimworld/get_ui_layout`. Before, a label drawn from a TaggedString or with `Listing_Standard.Label` had two entries with the same rectangle.
- Report the correct screen rectangles for listing controls in `rimworld/get_ui_layout`, such as the checkboxes of the options dialog. Before, when a listing did not start at the left or top edge of its group, its controls were reported too far right or down.
- Add `rimworld/list_pawns`. It lists every living pawn on the current map with its role, current hostility, faction, position and job, so an agent can find prisoners, animals and raiders for `rimworld/get_pawn_details`. A pawn that a building holds, such as an entity on a holding platform or a colonist in a cryptosleep casket, is listed with `heldBy` and the cell of the building. The reply is paged.
- Add `rimworld/list_buildings`. It lists the current map's buildings with position, the cells they cover, rotation, faction, hit points and power state, filtered by def, architect category or player ownership. An unknown def or category fails. The reply is paged.
- Add `rimworld/get_map_summary`. It reads the current map in one call: date, weather, temperature, active game conditions, wealth and pawn counts. The pawn counts use the pawns and roles of `rimworld/list_pawns`, so they include pawns that a building holds, and `held` counts those.
- Pause and unpause correctly while a window, a long event or a cutscene forces a pause. Before, the bridge took the forced pause for a real pause. An unpause could pause the game, a pause could leave the game running after the window closed, and `rimworld/play_for` paused the game that it had to run. `rimworld/pause_game` now also reports `timeSpeed` and `forcePaused`.
- Refuse a number that is not a time speed in `rimworld/set_time_speed` and the play tools. Before, `5` was accepted and the game stopped without being paused.
- Refuse `rimworld/switch_language` outside the main menu. A language switch reloads all game data, and in a running game it destroyed the game.
- Return the loaded game from `rimworld/load_game_ready`. With the default readiness, a load from a running game could return at once, with the state of the old game.
- Move a mod down to the requested index with `rimworld/reorder_mod`. Before, a move down landed one slot short, and a move down by one did nothing.
- Report `saved: false` and the reason from `rimworld/set_mod_enabled` and `rimworld/reorder_mod` when RimWorld started with a `-mod` command-line mod list. RimWorld does not write ModsConfig.xml then.
- Show the text of every letter in `rimworld/list_letters`, also of letters that are not choice letters, such as the Biotech growth moment. A growth moment also reports its passion and trait choices. Letter and alert text no longer contains name tags such as `(*Name)`.
- Draft colony mechs and colony ghouls with `rimworld/set_draft`. The tool now uses the game's draft toggle, so the game's rules apply. A downed colonist, a mech without its mechanitor and a pawn in a ritual cannot be drafted, and the reply gives the game's reason. Before, the tool found colonists only and drafted every colonist it found.
- Select any spawned pawn of the current map with `rimworld/select_pawn`, for example an animal or an enemy. Before, it selected colonists only.
- Refuse a gizmo that is not a command in `rimworld/execute_gizmo`, such as the psyfocus bar or the hemogen slider. Before, the call reported success and did nothing. `rimworld/list_selected_gizmos` marks these gizmos with `executable: false`. A gizmo id no longer changes with the description or the top-right label of the gizmo.
- Add `identity` to `rimworld/get_pawn_details`: faction leadership, ages, life stage, developmental stage, guest status, xenotype and genes, ideoligion and role, royal titles, psylink level, abilities, mutant and the overseer of a mech. A field is left out when its DLC is not active. A held pawn now reports the map and the cell of the building that holds it.
- Let debug actions target a pawn that a building holds, as the game's own debug tool does.
- Hide the Architect designators that the game hides, for example a building whose research is not finished. `rimworld/select_architect_designator` and `rimworld/apply_architect_designator` refuse them unless god mode is on. Before, colonists could build such blueprints.
- Select a floor or another dropdown child as the game does. Before, the bridge selected the dropdown itself, and the next map click threw an error. Dropdown ids also no longer change when another child is used, and designator ids no longer depend on the game language.
- Grow a zone from `rimworld/set_zone_target` as the game does. It takes unzoned cells that connect to it. Before, it also took the cells of other zones, so two zones could claim one cell. The reply now names the zone that got the cells and counts only those cells.
- Report the terrain under a floor, the foundation, Biotech pollution and Odyssey vacuum in `rimworld/get_cell_info` and `rimworld/get_cells_info`.
- Refuse a building that does not fit in the map in `rimworld/spawn_thing`. Before, a large building at the map edge caused an error log and an exception.
- Refuse map clicks while the world view is open. Before, a map click could act on the world map, for example give a caravan a travel order. Camera jumps to the map now close the world view.
- Close the dialog that a player sees with `rimworld/close_window` without a type. Before, it often closed an invisible helper window.
- Deselect the selected Architect designator with `rimworld/press_cancel` when no window takes the cancel, as the Escape key does. Before, the designator stayed selected, and the next map click placed it again.
- Stop a companion tool at its timeout. Before, a companion tool that never finished blocked the connection.
- Skip a companion tool whose parameter or return type cannot load, for example a type from a disabled mod, and keep the other tools. Before, such a tool stopped the bridge from starting.
- Reject a companion that reuses a tool name as a whole. Before, some of its tools stayed callable from scripts while discovery reported it as failed.
- Report an unknown tool name in a script as a failed step, with the output and the steps before it. Before, the whole script report was lost.
- Use Lua semantics for `%` and `==` in `rimbridge/run_lua`. `-1 % 5` is 4, and two strings are equal only when their text is equal, so `"1,5" == "15"` is false. A NaN value no longer stops a comparison with an error.
- Refuse `rimbridge/run_lua` and `rimbridge/run_lua_file` inside a script, as `rimbridge/run_script` already was. A nested run got a new time and statement budget and could recurse until the game crashed.
- Report float-menu option rectangles as the game lays them out. Before, options in later columns were off by a pixel per column, some options landed in the wrong column, and a scrolled menu was not taken into account.
