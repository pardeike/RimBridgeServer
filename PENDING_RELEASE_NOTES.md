- Tool replies to AI agents are much smaller and no longer exceed client output limits. Large lists (map cells, UI layouts, mods, saves, capabilities, debug-action search results, architect designators) are paged with an `offset`, and every reply carries the current game tick.
- UI layouts list only the elements visible in their scroll views and count the rest; `includeOffscreen` returns everything.
- Each zone rectangle now becomes its own zone unless an existing zone was chosen with `set_zone_target`; the result names the zone and whether it was created.
- `apply_architect_designator` accepts a material (`stuffDefName`) and a `rotation`; designator lists show footprint size, rotation and material support.
- New `rimworld/list_plans` reports planning marks with their bounds; cell info names the plan and the rotation of things.
- Pop-up option menus opened by gizmos or UI clicks stay open and can be read and chosen with the context-menu tools.
- `press_cancel` ends an active debug tool, and `get_ui_state` reports it.
- Debug-action search answers within about five seconds and says when deeper menus were not searched yet.
- Lua scripts accept `{}` as call arguments, `field or default` on missing fields, `..` concatenation and any `print` label, with a larger statement budget; script reports are compact.
- `spawn_thing` suggests close matches for unknown defs, and inspecting things without inspect tabs (such as coolers) no longer fails.
- Unknown or misspelled tool arguments produce a warning that lists the valid parameters instead of being silently ignored.
- RimWorld keeps running in the background for automation even after the game re-applies its preferences, for example when a Multiplayer session ends.
- `open_window_by_type` no longer fails when reflection-only assemblies are loaded.
